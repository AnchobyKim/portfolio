# Gameplay / Client Programmer Portfolio

아래 링크에서 실제 gameplay media와 상세 기술 사례를 포함한 포트폴리오를 확인할 수 있습니다.<br>
[포트폴리오 보기](https://anchobykim.github.io/portfolio/)

## AInvil

게임 규칙에서 구현 책임과 Unity 실행 대상을 정리하고 검증 증거까지 연결하는 AI-assisted development workflow입니다.<br>
개발자가 architecture, state model, interface, acceptance criteria와 최종 판단을 소유합니다.

[Repository](https://github.com/AnchobyKim/AInvil)

## Action Required

1993년 아파트 경비실을 배경으로 19일 동안 완성한 CCTV 감시 호러 playable demo입니다.<br>
AInvil과 Unity MCP를 실제 제작에 적용했으며, 공개 WebGL 기록은 현재 데모와 다를 수 있습니다.

[Repository](https://github.com/AnchobyKim/GeummongnyeonApartments)

## GashaGame / VASSALIA

같은 50-unit auto-battler domain을 service-backed hybrid와 deterministic standalone runtime으로 구현했습니다.<br>
State ownership, deterministic combat, encounter validation과 atomic transaction의 경계를 비교합니다.

[VASSALIA Repository](https://github.com/AnchobyKim/VASSALIA) · [GashaGame Repository](https://github.com/AnchobyKim/GashaGame)

## SOE

3D top-down survivor 팀 프로젝트에서 gameplay prototype과 환경·보스·전투 통계 runtime을 구현·통합했습니다.<br>
저장소는 개인 수정·테스트용으로, 현재 팀 프로젝트 버전과 차이가 있을 수 있습니다.

[Repository](https://github.com/AnchobyKim/SOOOOOOE)
